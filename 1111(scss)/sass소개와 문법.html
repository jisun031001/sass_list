sass소개와 문법

sass - Syntactically Awesome StyleSheet의 줄임말

scss - Sassy css의 줄임말

css pre-procesor(전처리기)로서 css반복을 줄여서 시간을 절약할 수 있게 해주는 css언어의 확장 언어다

css를 좀 더 효율적으로 작성하고 유지보수하기 쉽게 만들어준다

장점 : 변수 및 조건문 등의 새로운 문법을 통해 css를 구조화하여 작업 가능하다

단점 : 코드가 지저분해질 수 있고 코드가 많아질수록 유지보수가 어렵다

프로그램설치는 sass공식 사이트에서 gui, cli방식의 프로그램들 중 자신이 편한 것으로 다운받는다

vs code에서는 별도록 확장프로그램을 지원하기 때문에 설치가능하다

1. sass, scss문법의 차이점

sass문법
중괄호{}와 세미콜론(;)이 필요없다
들여쓰기(tab키)를 사용하여 코드 구조를 나타낸다
구문이 더 간결하고 python스타일과 비슷하다
    sass 작성 예)
    $primary-color:#333333;
    body
      background:$primary-color;
      color:#fff;

    nav
      ul
        margin:0px;
        padding:0px;
        li
          list-style:none;
          margin-top:10px;
scss문법
css문법과 매우 유사하다
중괄호와 세미콜론을 사용한다
기존 css와 호환성이 높다
    scss 작성 예)
    $primary-color:#333333;
    body{
      background:$primary-color;
      color:#fff;}

    nav{
      ul{
        margin:0px;
        padding:0px;
        li{
          list-style:none;
          margin-top:10px;}
      }
    }

sass, scss 둘 중 어느것아 더 좋은가?

scss 권장:
css와 문법이 거의 같아 기존 css파일과 통합하기 쉽다
팀원들이 css에 익숙하다면 scss가 더 쉽게 받아들여진다
최신 문법과 기능이 주로 scss에서 지원되며, sass는 유지보수용으로만 사용한다
sass 공식 문서에서도 scss사용을 권장한다
sass 사용 이유:
더 간결한 문법을 선호하거나, 기존 sass스타일을 유지해야하는 프로젝트에 유리하다
결론
scss를 사용하는것을 권장
더 널리 사용되며 유지보수에 유리
최신 기능 지원 및 호환성 뛰어남
