css방법론

css방법론은 대규모 프로젝트 작업시 css코드베이스의 유지 보수성, 재사용성, 확장성을 향상시키기 위해 사용되는 일련의 규칙

이러한 방법론들은 css코드의 구조를 개선하고, 개발자들이 일관성있는 방식으로 스타일을 작성할 수 있도록 한다

1. 방법론의 종류

  1. oocss(object oriented csss)

    css를 객체로 분해하여 스타일을 정의하는 방법론으로 css를 객체 지향 프로그래밍 원리에 따라 구조화하여 재사용 가능한 컴포넌트를 만들고, 중복 코드를 줄이는 것을 목표로 한다 예) 버튼 서식(로그인, 회원가입, 네이버 로그인, 카카오 로그인)

  2. smacss(scalable and modular architecture for css)

    css코드를 5가지 유형 (기본, 레이아우스 모듈, 상태, 테마)으로 나누어 규칙을 적용하고, 모듈화된 구조를 구축하여 확장성을 높이는 방법론이다 예) 다크모드, 카드 디자인

  3. bem(block element modifier)

    ui를 독립적인 블록으로 분리하고, 블록 내의 요소와 수정자를 정의하여 클래스 이름을 규칙적으로 구성하는 방법론이다

2. 방법론의 장점, 단점

oocss
장점 : 코드 재사용성 증가, 중복 코드 감소, 유지보수 용이성
단점 : 배우기 어렵고 복잡하다
smacss
장점 : 모듈화된 코드, 확장성이 용이하다, 코드 관리가 용이하다
단점 : 규칙을 준수하기가 어려우며 오버헤드 발생 가능성이 존재
bem
장점 : 구조화된 코드, 클래스명 규칙을 정하여 사용, 유지보수의 용이성이 높고 예측 가능한 코드
단점 : 긴 클래스명이 존재, 복잡한 구조를 가짐


css방법론은 프로젝트의 규모와 복잡성에 따라 적절하게 선택하여 적용하는 것이 중요하고, 각 방법론의 장,단점을 파악하여 팀의 개발 환경에 적용한다. 한가지 방법을 선택하는 것이 아니라 상황에 마덱 프로젝트 규모에 맞게 적절하게 혼합하여 사용한다.
